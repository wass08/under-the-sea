# Deliberate Lab burst tuning

The Lab now supplies an explicit `LabReleaseProfile` to the shared `releaseShards` in `src/lib/release.ts`. Omitted profile (or `'aquarium'`) retains the existing aquarium formulas, RNG consumption, geometry, impulse/mass conversion and torque/inertia conversion. No `src/scene/*` or `src/aquarium.ts` file was edited. L1 deliberately retains its naive release; its new controls are disabled and labelled for levels2–3.

The L2/L3 velocity front uses speed `min(14, impulse*(2.2+6.8*exp(-distance*falloff)))`, radial fraction `sqrt(1-forward²)` and pane-normal fraction `forward`. Defaults are impulse1.6, falloff3.8, forward0.6 and spin1.0. At the default centre strike, L3's fastest body starts at12.37 units/s; outer bodies start near3.54. All bodies receive their impulses together: the visible outward wave is produced by the velocity gradient, not scheduled ring releases. The initial core clears first while the outer plates lag. This deliberately changes L2 from its old almost-normal, uniform-speed launch to a radial fan.

Small fragments receive an area-dependent spin bonus in addition to the impact falloff; the requested angular speed is capped at14rad/s. The shared conditioned inertia converts this to an angular impulse. Linear impulses still use actual body mass. Density-invariance tests cover the new profile as well as the old aquarium default.

Lab L2/L3 opt into the existing0.2s small-world/0.4s crowded-world mutual-contact grace while keeping floor and plinth contacts. Supported drag is6/5 through an optional world setting, applied only after a valid support contact. Airborne0.45/1.2 and quiet8/20 drag remain unchanged; native sleep handles rest, with no new forced-sleep deadline. Existing connected-cell grouping is retained (41 bodies for L2,75 for L3 at220 cells). The shared solver's launch-fidelity schedule is unchanged from the previous pass.

Tweakpane exposes impulse0.5–3, falloff0.5–6, forward0.15–0.9 and spin0–2 under “Burst · next break.” These are copied into the release options only on the next break. The existing settings store preserves them across resets, level changes and bench changes. Real input editing was tested, including frozen current poses remaining unchanged, persistence through L3→L2→L3, and application on the next break. Reveal, freeze and slow motion use their existing paths. Only the L2 explanatory text changed, since “no sense of an impact point” is no longer true.

## Measurements

`impulse-compare.mjs` uses fresh WebGPU pages,1600×1000,DPR1.5, the same camera as the earlier burst frames. The Lab is reset while frozen, clicked at the projected pane centre (rounded impact[0.02,0.01]), then unfrozen. `?labRelease=before` selects the old profile in the same build. The before sources are saved under `verify/impulse-before/`. The main-page comparison uses its default camera and pristine Space shatter; the Lab flag has no effect there.

The optional `burstProbe` records every body's COM, velocity, angular velocity, initial impact distance, damping regime and sleep state for60 fixed steps. Outward velocity is the signed dot product of velocity with the current3D direction from impact to body COM. Radial means/p90 and positive-outward fractions are sampled at exact6/15/30 steps (0.1/0.25/0.5s). Cloud radius is p90 distance from impact to COM at15/30/60 steps. Retention is the ratio of median speeds at0.25/0.1s. These are per-body metrics, with no area/mass weighting. Full raw data and frame times are in `impulse-{before,after}/{L2,L3,main}.json`.

The L3 core (initial distance<0.35) has11 bodies. Its radius at0.5s increases1.740→3.742 units; mean core speed increases3.232→3.796 units/s, with8/11 core bodies still moving faster than0.5 units/s. The overall cloud widens while supported lower shards decelerate, so the aggregate speed-retention ratio is lower than before; this does not mean the airborne core has stopped. At2s the image shows fragments spread over the floor and plinth, with some bodies still finishing their settling/native sleep timers. At5s all bodies are natively asleep in both the library fixture and the full Lab suite.

FPS medians use wall-time0.1–1.5s airborne and5–6s settled. The final L2/L3 sampling ran without concurrent browser or physics tests. Both measure60.24 FPS airborne and59.88 FPS settled. Screenshots are frozen at exact0.1/0.25/0.5/1.0s solver poses; their camera state is asserted equal to the old burst frame camera. An additional2s frame and all before comparison frames are retained. The fast core can travel outside the original framing by1s; the camera was not widened to make the spread look larger.

## Validation

TypeScript and the dist-perf build passed. `lab.mjs` passed L1–L3 freeze/reset,3–4s rest, native sleep by5s, slow motion and navigation tests without changing their tolerances or fixtures. `library.mjs` keeps all existing Run D/K/N expectations and now imports an additional profile suite. That suite compares the aquarium against the saved pre-tuning release/physics sources for300 steps, asserting every position, rotation and linear/angular velocity bit-identical. It separately verifies new Lab trajectory determinism across render chunking,10× density invariance, bounded initial spin and native rest/sleep. The main-page browser metrics and all first60 per-body states also compare exactly equal. No pinned aquarium expectation was updated; no old trajectory assertion was weakened.
